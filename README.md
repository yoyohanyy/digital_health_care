# SleepManager Mobile App

수면 데이터를 기반으로 사용자의 수면 상태를 분석하고,  
카카오 챗봇과 연동하여 **개인화된 수면 피드백**을 제공하는  
**Flutter 기반 모바일 애플리케이션**입니다.

본 앱은 수면 데이터 시각화와 사용자 맞춤 피드백 제공을 목표로 설계되었습니다.

---

## 🛠 Tech Stack

- Flutter
- Dart
- Firebase Firestore
- Kakao SDK
- Android Studio

---

## 📌 Key Features

### 1. Kakao Login
- Kakao SDK를 활용한 모바일 앱 카카오 로그인 구현
- 사용자 고유 식별자(ID) 기반 사용자 관리

### 2. Sleep Data Management
- 사용자 수면 데이터 저장 및 조회
- Firebase Firestore 기반 데이터 관리

### 3. Sleep Data Visualization
- 수면 시간 및 패턴 시각화 UI 구현
- 사용자 수면 상태를 직관적으로 확인 가능

### 4. App–Chatbot Integration
- 모바일 앱과 카카오 챗봇 사용자 연동
- 인증 코드를 통한 앱–챗봇 사용자 매핑
